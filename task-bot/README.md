# Task Bot: Telegram-бот для завдань і нагадувань

Пишеш боту, що треба зробити, а він нагадує в потрібний час.

- **Текстом:** «завтра о 9 забрати посилку», «у пʼятницю ввечері подзвонити мамі».
- **Пересланим повідомленням:** перешли боту прохання, наприклад від дружини. Він виділить завдання,
  запамʼятає, від кого воно, і спитає, коли нагадати, якщо час не вказано.
- Кілька справ в одному повідомленні стають кількома завданнями.
- У нагадуванні є кнопки: ✅ Виконано, +15 хв, +1 год, Завтра 9:00.
- `/list` показує активні завдання, `/done` виконані.

Голосові повідомлення поки не підтримуються, це наступний етап.

## 1. Що потрібно

| Що | Де взяти |
|----|----------|
| Python 3.11+ | https://www.python.org/downloads/ (на Windows постав галочку «Add Python to PATH») |
| Токен бота | Telegram → @BotFather → `/newbot` → придумай імʼя → скопіюй токен |
| Ключ Anthropic | https://console.anthropic.com → Settings → API Keys → Create Key (рахунок треба поповнити, від 5 $) |

## 2. Налаштування

1. Скопіюй файл `.env.example` у `.env`.
2. Відкрий `.env` і впиши `BOT_TOKEN` та `ANTHROPIC_API_KEY`.
3. Щоб ботом міг користуватися лише ти:
   - запусти бота (крок 3) з `ALLOWED_USER_IDS=1`;
   - напиши боту будь-що, і він відповість «Твій ID: 123456789»;
   - впиши цей ID: `ALLOWED_USER_IDS=123456789`. Кілька людей пиши через кому;
   - перезапусти бота.

### Модель
За замовчуванням стоїть `claude-opus-5-5`: найкраще розуміє заплутані фрази, приблизно 1 цент за повідомлення.
Дешевший варіант `CLAUDE_MODEL=claude-haiku-5-5` коштує приблизно в 40 разів менше, і для звичайних
фраз його має вистачати.

## 3. Запуск на компʼютері

**Windows (PowerShell), у папці `task-bot`:**
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m bot.main
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

Бот працює, поки відкрите це вікно. Зупинити його можна клавішами `Ctrl+C`. Наступного разу достатньо
активувати `.venv` і виконати `python -m bot.main`.

Завдання зберігаються у файлі `data/tasks.db`. Нагадування не загубляться, якщо бот перезапустити.
Якщо бот був вимкнений у момент нагадування, він надішле його одразу після запуску.

## 4. Запуск на сервері 24/7 (Docker)

На будь-якому VPS з Docker:
```bash
docker compose up -d --build
```
Бот сам підніметься після перезавантаження сервера. Подивитися логи: `docker compose logs -f`.

## Структура

```
bot/main.py     ← обробка повідомлень, кнопки, цикл нагадувань
bot/parser.py   ← розбір тексту на завдання й час через Claude
bot/db.py       ← база SQLite
bot/config.py   ← налаштування з .env
```
