# PANCHUK.dev — сайт-портфоліо (HTML / CSS / JS)

Сайт не потребує збірки, фреймворків і npm. Відкрийте `index.html` у браузері, і він запрацює.

```
index.html          ← українська версія
en/index.html       ← англійська версія
css/style.css       ← усі стилі (спільні для обох мов)
js/main.js          ← тема, «Показати більше», форма
css/fx.css, js/fx.js          ← базові анімації, прелоадер, курсор
css/fx-pro.css, js/fx-pro.js  ← плавний скрол, горизонтальна галерея робіт, стрічки, ефекти скролу
js/vendor/lenis.min.js        ← бібліотека плавного скролу Lenis 1.3.27 (MIT)
images/works/       ← скріни робіт
favicon.svg, robots.txt
```

## Що де змінювати

- **Тексти і ціни:** редагуйте прямо в `index.html` та `en/index.html`.
- **Нова робота:** скопіюйте блок `<a class="win" …>…</a>` у секції `#works` і замініть посилання, назву, підпис, теги та скрін. Скрін покладіть у `images/works/`, бажано 1600px завширшки. Кнопка «Показати більше» потрібна, тільки коли робіт більше шести. Її розмітку і стилі (клас `.wins-more`) можна додати за потреби.
- **Форма заявок:** у `js/main.js` впишіть адресу в `FORM_ENDPOINT`, наприклад з Formspree (https://formspree.io/f/…). Поки адреса порожня, форма просить написати в Telegram.
- **Домен:** у `<head>` обох сторінок замініть `https://panchuk.dev` у тегах canonical і hreflang на свій домен.

## Хостинг

Залийте всю папку як є на будь-який статичний хостинг: Netlify (перетягнути папку), GitHub Pages, Cloudflare Pages, Vercel або звичайний хостинг через FTP.

## Анімації

Усі анімації вимикаються, якщо в системі ввімкнено «Зменшити рух». Щоб прибрати їх повністю, видаліть з обох сторінок рядки, що підключають `fx.css`, `fx-pro.css`, `fx.js`, `lenis.min.js` і `fx-pro.js`, а також маленький скрипт у `<head>`, що додає клас `fx`.
